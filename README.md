# 워프러시 (wprush)

엑셀에서 복사한 주제 목록을 붙여넣으면, AI가 주제마다 **구글 애드센스 승인 기준을 지킨 정보성 글**과
썸네일을 만들어 **워드프레스에 임시저장**해 주는 로컬 대시보드입니다.

네이버 블로그용 [파이어러시](https://github.com/jettyy/firerush),
구글 블로거용 [블로거러시](https://github.com/jettyy/blogger)와 같은 방식이고,
글을 올리는 방법과 글이 지켜야 할 규칙을 워드프레스·애드센스에 맞춰 바꿨습니다.

- 글 생성: `claude -p` (Claude Code CLI 헤드리스 모드) → **구독 요금제 그대로 사용**, 토큰 종량 과금 없음
- 자료 조사: 글을 쓰기 전에 **웹 검색으로 최신 자료와 기사를 찾아** 그 내용만 근거로 씀. 출처는 글 끝에 링크로 붙음
- 애드센스 준수: 분량·문체·표·구조를 **프로그램이 직접 검사**하고, 어긋나면 그 항목만 짚어 다시 쓰게 함
- 워드프레스 접속: **공식 REST API + 응용 프로그램 비밀번호**. 브라우저 로그인도, 화면 자동화도 없음
- 본문 형식: **구텐베르크 블록 마크업**. 문단·소제목·목록·표가 블록 에디터에서 그대로 편집됨
- 함께 지정: 대표 이미지, 카테고리, 태그, 영문 슬러그, 요약(발췌문)
- 순위 글: `TOP100` 은 물론 개수를 안 쓴 `전국 대학 순위` 도 **100위까지** 뽑음. 뒤 구간은 지방·소규모까지 넓혀서 채움
- 썸네일: 원하면 **이미지 API가 제목·띠·뱃지까지 통째로** 그립니다. 언제나 가장 싼 모델부터 쓰고, 한글이 깨졌을 때만 한 단계 올라갑니다
- 결과물: 워드프레스 초안 + `post.md`(구텐베르크에 붙여넣을 마크다운) + `preview.html`
- 발행은 하지 않습니다. **임시저장까지만** 하고, 사실 확인과 발행은 사람이 합니다.

## 블로거 버전과 달라진 점

| | 블로거러시 (블로거) | 워프러시 (워드프레스) |
|---|---|---|
| 접속 | Playwright 로 구글 로그인 창 | **REST API + 응용 프로그램 비밀번호** |
| 브라우저 | 로그인용 + 썸네일용 2개 | 썸네일 렌더링용 1개뿐 |
| 본문 넣는 법 | 에디터의 [HTML 보기]에 입력 | **API 로 한 번에 전송** (선택자 깨질 일 없음) |
| 본문 형식 | 인라인 style 을 박은 HTML | **구텐베르크 블록 마크업** (색·여백은 테마에 맡김) |
| 소제목 | `<h3>` | `<h2>` + `<h3>` (글 제목이 이미 H1) |
| 이미지 | 에디터에 업로드 후 HTML 떼어내기 | 미디어 API 업로드 → **대표 이미지**로도 지정 |
| 분류 | 라벨 | 카테고리 1개 + 태그 여러 개 (ID 로 정확히 지정) |
| 주소 | 자동 | AI가 만든 **영문 슬러그** |
| 더보기 | `<!--more-->` | `<!-- wp:more -->` 블록 |
| 글 규칙 | 일반 블로그 글 | **애드센스 승인 기준 자동 검사** |

## 자료 조사 (웹 검색)

모델이 아는 일반론만으로 쓴 글은 수치가 두루뭉술하거나 아예 틀립니다.
그래서 글을 쓰기 전에 **실제로 웹 검색을 해서** 사실과 출처를 먼저 모읍니다.

**조사와 집필을 두 번의 호출로 나눕니다.**

1. **조사** — 검색 도구를 켜고 사실과 출처 URL 만 모읍니다 (글은 쓰지 않습니다)
2. **집필** — 검색 도구를 끄고, 모아온 자료만 보고 글을 씁니다

한 번에 시키지 않는 이유가 있습니다. 도구를 쓰면서 동시에 엄격한 JSON 을 뱉게 하면
검색 결과를 설명하는 산문이 앞뒤로 붙어 파싱이 자주 깨집니다.
나눠서 얻는 것이 하나 더 있습니다. 조사 결과가 `research.json` 으로 남아서
발행 전에 **이 글이 무엇을 근거로 쓰였는지** 사람이 직접 확인할 수 있습니다.

조사 단계에서 챙기는 것들:

- 오늘 날짜를 알려줘 "최신"의 기준을 잡습니다
- 공식 출처(정부기관, 공공기관, 주관 기관)를 민간 블로그보다 우선합니다
- 중요한 수치는 두 곳 이상에서 교차 확인하게 합니다
- **지어낸 URL 을 걸러냅니다.** `example.com` 이나 점 없는 호스트는 버립니다
- 확인하지 못한 내용은 `unverified` 로 따로 받아, 본문에서 단정하지 않게 합니다
- **검색이 실제로 몇 번 돌았는지 셉니다.** 0회면 "검색했다고 말만 한" 결과라서 경고를 띄웁니다

집필 단계에서는 "구체적인 수치, 일정, 기준은 조사 자료에 있는 것만 쓰고,
없으면 여지를 두고 쓰라"고 지시합니다. 본문에 URL 을 직접 적지 못하게 하고,
출처는 글 맨 끝에 링크 목록으로 따로 붙입니다.

실제로 돌려본 예 (`2026년 취업률 높은 국가기술자격증 TOP 3`):

```
검색 5회 → 사실 6건, 출처 8건, 미확인 4건
고용노동부 2025년 3월 보도자료에서 전기산업기사 73.9%, 산림기능사 71.9% 확인
"2026년 기준 취업률 통계는 아직 발표되지 않았다" 를 미확인 항목으로 표시
```

> **비용과 시간이 늡니다.** 검색이 붙으면 글 하나에 3~5분, 호출이 2회로 늘어납니다.
> 급하게 많이 돌려야 한다면 4번 칸에서 자료 조사를 끄면 됩니다. 대신 최신 수치는 못 씁니다.

> **조사해 왔다고 사실이 보장되지는 않습니다.** 검색 결과에도 틀린 내용이 있고,
> 모델이 자료를 잘못 읽을 수도 있습니다. 그래서 이 프로그램은 발행하지 않고 임시저장만 합니다.
> 미리보기 맨 위의 **확인하지 못한 내용**부터 보시고, 수치는 원문에서 대조하세요.

## 애드센스 승인 규칙을 어떻게 지키는가

이 프로그램의 핵심입니다. 규칙을 프롬프트에 적어 넣는 것만으로는 부족합니다.
모델이 안 지킨 채로 나와도 그대로 저장되기 때문입니다.

그래서 `src/content/adsense.js` 한 곳에 규칙을 정의하고, **같은 정의에서 두 가지를 만들어 냅니다.**

1. 글을 쓰기 전 프롬프트에 들어갈 **지시문**
2. 나온 글을 실제로 검사하는 **검사기**

검사에 걸리면 걸린 항목만 짚어 다시 쓰게 하고(기본 1회), 통과할 때까지 확인합니다.
지시와 검사가 한 파일에 묶여 있어서 따로 놀 수가 없습니다.

| 규칙 | 검사 내용 |
|---|---|
| 분량 | 공백 제외 1,800자 이상 (설정에서 조정) |
| 종결어미 | `~습니다`, `~입니다` 형태가 85% 이상. `~함`, `~임` 개조식은 발견 즉시 실패 |
| 소제목 구조 | H2 3개 이상 + H3 1개 이상. 본문에 H1 금지 |
| 선정 기준 | 서두에 "무엇을 기준으로 골랐는지" 단락이 있는지 |
| 비교 표 | 2행 2열 이상의 표가 최소 1개 |
| 불렛 포인트 | 목록이 최소 1개 |
| 항목별 상세 | 항목형 글에서 각 항목마다 세부 소제목 3개 이상 (상세 설명 / 자격 요건 / 활용 분야 / 장단점 / 준비 팁) |
| 서두 인사말 금지 | "안녕하세요", "이번 포스팅에서는", "알아보겠습니다" 로 시작하지 않는지 |
| 기호·이모지 | 별표, 화살표, 이모지 등 장식 기호가 본문에 있는지 |
| 마무리 | 요약과 독려가 담긴 마무리 단락이 충분한지 |

결과는 작업표의 **준수** 열에 `10/10` 처럼 표시되고, 마우스를 올리면 항목별 판정이 보입니다.
`설정 > 끝내 못 고치면 저장하지 않기` 를 켜면 규칙을 못 지킨 글은 아예 올리지 않습니다.

> 검사기는 형식을 봅니다. **사실관계는 사람이 확인해야 합니다.**
> 웹 검색으로 근거를 모으긴 하지만 검색 결과에도 틀린 내용이 있으니,
> 발행 전에 수치와 제도 내용을 원문에서 대조하세요.

## 주제에 따라 글 모양이 달라집니다

애드센스 규칙은 "각 항목마다 상세 설명, 자격 요건, 활용 분야, 장단점, 팁을 넣을 것" 을 요구합니다.
그래서 항목이 몇 개냐에 따라 구조를 바꿉니다.

| 주제 예시 | 모양 | 어떻게 쓰는가 | 호출 횟수 |
|---|---|---|---|
| `국가기술자격증 TOP 5` | 항목별 상세형 | 항목마다 H2 섹션 1개 + H3 세부 소제목 5개 | 1회 |
| `겨울 캠핑 장비 추천` | 항목별 상세형 | 개수는 AI가 정합니다 (5개 내외) | 1회 |
| `전국 대학교 순위` | 대형 비교표형 | **개수를 안 써도 100위까지** 뽑습니다 | 3회 |
| `유튜브 구독자 TOP100` | 대형 비교표형 | 표를 50행씩 나눠 받고, 대표 항목만 상세하게 | 3회 |
| `전세 계약 전 확인할 서류` | 정보 정리형 | H2 소제목 중심 + H3 세부 소제목 | 1회 |

13개 이상이면 항목마다 다섯 항목씩 쓰는 것이 현실적으로 불가능해서 표 중심으로 넘어갑니다.

### 순위를 100위까지 채우는 법

개수를 안 쓴 순위 주제(`전국 대학 순위`, `수도권 대학 서열`)는 예전에 항목 5개짜리
글로 잡혀서, 정작 원하던 "많이 담긴 순위표"가 안 나왔습니다. 이제 **설정한 목표 개수
(기본 100)** 만큼 큰 표로 갑니다. 주제에 숫자가 있으면(`TOP 30`) 그 숫자를 따릅니다.

큰 순위표가 깨지는 지점은 늘 **뒤쪽**입니다. 상위권은 누구나 아는 이름으로 금방 차지만,
50번을 넘어가면 모델이 앞에서 쓴 이름을 다시 쓰거나 "이하 생략" 하고 멈춥니다.
그래서 구간마다 어디까지 넓혀야 하는지 명시적으로 알려줍니다.

| 구간 | 지시 |
|---|---|
| 앞 25% | (없음) |
| 25~50% | 수도권 밖과 중견 규모까지 넓히세요 |
| 50~75% | **지방과 덜 알려진 곳**까지, 광역시와 각 도 단위로 고르게 훑으세요 |
| 뒤 25% | **규모가 작거나 특수 목적인 곳**까지. "더 이상 없습니다" 라고 답하지 마세요 |

여기에 더해 이미 나온 이름을 프롬프트에 넣어 제외시키고, 돌아온 행의 **이름이 겹치면
버립니다.** 이게 없으면 100행짜리 표에 같은 이름이 세 번 들어갑니다.
빠진 번호는 연속 구간으로 묶어 최대 2번 더 채웁니다. 한 바퀴 돌았는데 한 줄도 안 늘면
더 돌려도 같으므로 남은 시도를 건너뜁니다.

실제로 `전국 대학교 순위` 로 돌려본 결과입니다.

```
100/100 채움 · 빠진 번호 없음 · 중복 0건 · 빈 칸 0개 · 84초 (2회 호출)
서울 23 · 경기 16 · 부산 9 · 경북 8 · 대전 7 · 전북 5 · 강원 4 · 광주 5 · 제주 1 ...
95~100위: 한국교통대, 극동대, 상지대, 제주국제대, 호남대, 광주대
```

## 썸네일 (선택)

기본값은 지금까지처럼 **HTML로 만드는 단색 썸네일**입니다. 추가 비용이 없습니다.
이미지 생성 API 를 붙이면 두 가지 방식 중에 고를 수 있습니다.

| 방식 | 어떻게 | 한글 |
|---|---|---|
| **통째로 그리기** (`full`, 기본) | 제목·띠·뱃지까지 그림 안에 다 그립니다. 포스터형 썸네일 | 이미지 모델이 그립니다. 가끔 뭉개집니다 |
| **배경만 그리기** (`overlay`) | 글자 없는 배경만 그리고 한글은 HTML 이 얹습니다 | 브라우저가 그려서 **절대 안 깨집니다** |

### 모델은 언제나 가장 싼 것부터

두 방식 모두 **가장 싼 모델부터** 씁니다. 통째로 그릴 때도 마찬가지입니다.
싼 모델이 한글을 뭉갤 수는 있지만 늘 그런 것은 아니고,
안 그래도 되는데 비싼 모델을 쓰는 쪽이 더 큰 손해이기 때문입니다.

대신 만들고 나서 **글자가 제대로 나왔는지 확인**하고, 실제로 깨졌을 때만 올라갑니다.

```
1) 가장 싼 모델로 그린다  →  글자 확인 통과  →  끝            ← 대부분 여기서 끝납니다
2) 깨졌으면 같은(가장 싼) 모델로 한 번 더                       ← 그냥 운이 나빴을 수 있습니다
3) 그래도 깨지면 다음으로 싼 모델로 한 번                       ← 이 모델이 한글을 못 그리는 것입니다
4) 그래도 깨지면 HTML 썸네일                                    ← 한글이 절대 안 깨집니다
```

확인은 만든 그림을 값싼 모델로 다시 읽어 "이 문구가 맞게 들어갔는지" 보는 것입니다.
글자 몇 개만 돌려받는 호출이라 값은 거의 들지 않습니다.
설정에서 끄면 이 확인 없이 한 번만 그리고 그대로 씁니다. (깨져도 그대로 올라갑니다)

### 어떤 문구가 그림에 들어가는가

글 하나를 쓸 때 AI 가 썸네일 문구도 같이 정합니다.

| 필드 | 예 |
|---|---|
| `posterLines` | `["4년제만 답이 아니다", "취업 최강 전문대"]` — 가장 크게 박힐 제목, 1~3줄 |
| `ribbon` | `"TOP 50 대공개 (2026 최신)"` — 제목 아래 띠 |
| `subline` | `"실무, 자격증, 현장 경험으로 골랐습니다"` — 맨 아래 한 줄 |
| `badge` | `"전문대"` — 구석 뱃지 |
| `keywords` | `["간호보건", "반도체", "자동차", "항공", "IT"]` — 아이콘 뱃지 |
| `scene` | 배경으로 그릴 장면 (영어) |

프롬프트에는 이 문구들을 **한 글자씩 그대로 적어 넣고** "이 글자 말고는 아무것도 쓰지 마라",
"모든 한글을 정확하게 그려라" 를 여러 번 반복합니다. 그냥 "제목을 넣어줘" 라고 하면
모델이 문구를 지어내면서 한글이 더 잘 깨집니다.

### 모델이 죽어도 알아서 넘어갑니다

구글은 이미 한 번 갈아엎었습니다. Imagen 4 의 `:predict` 엔드포인트는 2026년 8월 17일에
종료되고 Gemini 의 `:generateContent` 로 넘어갔습니다. 그래서 이렇게 만들었습니다.

- **두 호출 형식을 모두 지원합니다.** `imagen-` 으로 시작하면 `:predict`, 아니면 `:generateContent`
- 고른 모델이 404 면 **다음으로 싼 모델로 자동으로 넘어가고**, 그 모델을 목록에서 뺍니다
- 키가 틀렸거나 한도에 걸린 경우는 다른 모델로 바꿔도 똑같이 실패하므로 **바로 알립니다**

모델 목록은 `GET /v1beta/models` 로 받아옵니다. 다만 **응답에 가격이 없어서**
싼 순서는 `src/content/imagegen.js` 의 `PRICE_TABLE` 로 정합니다.
표에 없는 새 모델은 이름의 등급(`lite` < `fast` < `flash` < `pro`)으로 짐작합니다.
목록은 하루에 한 번만 받아 `data/image-models.json` 에 저장합니다.

### 쓰는 법

1. [aistudio.google.com](https://aistudio.google.com/apikey) 에서 API 키를 발급합니다 (무료 등급 있음)
2. 대시보드 **6번 설정**을 펼쳐 키를 넣고 "썸네일을 이미지 API로 만들기" 를 켭니다
3. **[이미지 API 테스트]** 를 누르면 실제 문구가 박힌 그림 한 장과 모델 목록이 나옵니다

```
성공 — gemini-3.1-flash-lite-image (Flash Lite) · 장당 약 $0.034 · 412KB
자동으로 가장 싼 모델을 골랐습니다.
글자 확인: 통과

쓸 수 있는 모델 (싼 순서):
→ gemini-3.1-flash-lite-image  $0.034  Flash Lite
   gemini-3.1-flash-image       $0.067  Flash
   gemini-3-pro-image           $0.134  Pro
```

**아래에 뜨는 그림에 한글이 제대로 박혔는지 직접 확인하세요.** 그게 100편의 품질을 좌우합니다.
자꾸 깨지면 "배경만 그리기" 로 바꾸시면 됩니다. 그쪽은 한글이 깨질 일이 없습니다.

| 설정 | 값 |
|---|---|
| 만드는 방식 | `full` 통째로 (기본) · `overlay` 배경만 |
| 이미지 모델 | **비워두면 자동** — 언제나 가장 싼 것부터 |
| 포스터 분위기 | `bold` 강렬 · `clean` 차분 · `playful` 친근 |
| 대략적인 비용 | 가장 싼 등급 기준 장당 $0.03 안팎 → 글 100편에 4천원 안팎 |
| 실패했을 때 | 경고만 남기고 HTML 썸네일로 진행 |

가격과 모델 이름은 자주 바뀝니다. [가격 페이지](https://ai.google.dev/gemini-api/docs/pricing)에서 확인하세요.

## 응용 프로그램 비밀번호 발급

로그인 비밀번호가 **아닙니다.** 이 프로그램만 쓸 수 있는 별도의 열쇠이고, 언제든 따로 폐기할 수 있습니다.

1. 워드프레스 관리자 → **사용자 → 프로필**
2. 아래로 내려 **응용 프로그램 비밀번호** 칸
3. 이름을 아무거나 적고 (예: `wprush`) **[새 응용 프로그램 비밀번호 추가]**
4. `xxxx xxxx xxxx xxxx xxxx xxxx` 형태의 비밀번호가 **한 번만** 표시됩니다. 그대로 복사
5. 대시보드 1번 칸에 사이트 주소 · 사용자 이름과 함께 넣고 **[연결 확인]**

칸이 보이지 않는다면 사이트가 http 이거나, 보안 플러그인이 기능을 꺼둔 경우입니다.

## 사용 흐름

1. **워드프레스 연결** — 사이트 주소, 사용자 이름, 응용 프로그램 비밀번호를 넣고 [연결 확인].
   성공하면 계정 권한과 카테고리 목록을 자동으로 읽어 옵니다.
2. **주제 붙여넣기** — 엑셀에서 주제 열을 복사해 그대로 붙여넣습니다.
   한 줄에 주제 하나로 인식하고, 탭으로 나뉜 경우 첫 열만 씁니다.
   머리글(`주제`, `제목` 등)과 중복은 자동으로 걸러냅니다.
3. **지침 & 예시** — AI에게 꼭 지키게 할 내용을 적고, 참고할 예시 글을 올립니다.
4. **준수 규칙 확인** — 최소 분량, 소제목 개수, 보정 횟수를 조정합니다.
5. **설정** — 모델, 독자, 썸네일, 대기 시간 등을 조정합니다.
6. **실행** — 주제를 하나씩 순서대로 처리합니다.
   진행 상황·준수 점검 결과·썸네일이 표에 실시간으로 표시되고,
   저장이 끝나면 **[초안 열기]** 링크가 생깁니다.
7. **확인** — 워드프레스 글 목록의 **임시글**에서 내용과 사실관계를 확인하고 발행하세요.

## 실패해도 멈추지 않습니다

주제 100개를 걸어놓고 자는 동안, 세 번째 주제에서 멈춰 있으면 곤란합니다.
그래서 기본값은 **한 주제가 안 되면 그냥 다음 주제로 넘어가는 것**입니다.

실패에도 종류가 있어서 다르게 다룹니다.

| 무슨 일 | 어떻게 |
|---|---|
| **AI가 주제를 거절** | **건너뜀**으로 표시하고 바로 다음 주제로. 재시도하지 않습니다 |
| 그 밖의 실패 | 설정한 횟수만큼 재시도한 뒤 **실패**로 두고 다음 주제로 |
| 사용량 한도 | 여기서만 **일시정지**합니다. 계속 돌려봐야 전부 실패하기 때문입니다 |

거절을 재시도하지 않는 이유가 있습니다. 같은 주제로 다시 물어보면 같은 대답이 옵니다.
호출만 버리고 시간만 늘어납니다. 그래서 한 번만 물어보고 넘어갑니다.

거절은 대개 **주제가 사실이 아닌 것을 지어내라고 요구할 때** 나옵니다.
예를 들어 "자영업자 다중대출 잔액 상위 업종 랭킹" 은 공개된 통계가 없어서,
모델이 "지어낸 수치를 확인된 것처럼 표시할 수 없다" 며 거절합니다.
주제를 조금 바꾸면 대개 써집니다.

- `확인된 위험 신호` → `일반적으로 거론되는 특징`
- `상위 업종 랭킹` → `자주 언급되는 업종과 그 배경`

거절 사유 전문은 작업표의 메시지에 **마우스를 올리면** 보입니다.
표에는 한 줄로 줄여 띄우고 원문은 따로 담아 둡니다.

> 설정에서 **연속 실패 시 멈춤**에 0이 아닌 값을 넣으면 예전처럼 멈춥니다.
> 워드프레스 연결이 끊긴 채로 100건을 돌려 전부 실패로 태우는 것이 걱정될 때 쓰세요.

| H2 소제목 개수 | 규칙상 3~4개 |
| 보정 재요청 횟수 | 검사에 걸렸을 때 다시 쓰게 할 횟수. 호출이 늘어나므로 1회 권장 |
| 끝내 못 고치면 저장하지 않기 | 켜면 규칙 미준수 글을 아예 올리지 않습니다 |
| 서두에 선정 기준 밝히기 / 자주 묻는 질문 넣기 | 승인 심사에서 정보성을 높이는 부분입니다 |
| 사용할 AI 모델 | 드롭다운에서 고릅니다. 목록에 없는 모델은 "직접 입력…"으로 |
| 말투 / 독자 | 프롬프트에 그대로 반영됩니다 (말투는 규칙을 벗어나면 검사에서 걸립니다) |
| "더 읽기" 넣기 | 도입부 뒤에 `<!-- wp:more -->`. 목록 화면에 도입부까지만 보입니다 |
| 태그를 워드프레스 태그로 등록 | AI가 뽑은 태그 3~6개를 찾거나 새로 만들어 붙입니다 |
| AI가 만든 영문 슬러그 사용 | 한글 주소보다 검색에 유리합니다 |
| 순위 글 목표 개수 | 개수를 안 쓴 순위 주제를 몇 위까지 뽑을지. 기본 100 |
| 썸네일 스타일 / 크기 | `auto`(AI 선택) · `minimal`(권장) · `bold` · `gradient` · `editorial` |
| 썸네일 배경을 이미지 API로 그리기 | 켜면 배경 그림만 생성하고 한글은 그 위에 얹습니다 |
| 이미지 API 키 | aistudio.google.com 에서 발급 |
| 이미지 모델 | **비워두면 자동** — 언제나 가장 싼 것부터 |
| 만드는 방식 | `full` 글자까지 통째로 (기본) · `overlay` 배경만 |
| 글자가 깨졌는지 확인하기 | 깨지면 다시 그리거나 다음 모델로. 끄면 깨진 채로 올라갑니다 |
| 썸네일을 본문에 넣기 / 대표 이미지로 지정 | 따로 켜고 끌 수 있습니다 |
| 썸네일에 이모지 허용 | 승인 심사에서는 꺼두는 편이 안전합니다 |
| 글 사이 대기 | 기본 20~60초 무작위. 호스팅의 요청 제한을 피합니다 |
| 재시도 횟수 | 실패한 주제를 자동으로 다시 시도하는 횟수 |
| 연속 실패 시 멈춤 | **0이면 멈추지 않고 끝까지** 갑니다 (기본). 설정이 잘못돼 전부 실패할 때 멈추고 싶으면 3 정도 |

설정 파일에서만 조정 가능한 항목:

- `claude.command` — `claude` 실행 파일 경로 (PATH에 없을 때)
- `claude.timeoutMs` — AI 응답 대기 시간 (기본 420초. 승인글은 길어서 넉넉히 잡았습니다)
- `run.chromiumPath` — 썸네일 렌더링에 쓸 크롬/크로미움 경로 (환경변수 `CHROMIUM_PATH` 도 가능)
- `image.timeoutMs` — 이미지 생성 대기 시간 (기본 120초)

## 추가 지침

대시보드 **3번 칸**에 쓰는 내용입니다. 입력하면 자동으로 저장됩니다.
프롬프트의 **맨 앞**과 **맨 끝**에 두 번 들어갑니다.

한 줄에 하나씩 쓰면 더 잘 지킵니다.

```
수도권 기준으로 설명할 것
비용은 대략적인 범위로만 언급할 것
마지막에 준비 체크리스트를 넣을 것
```

블로거판과 한 가지 다릅니다. 거기서는 지침이 **모든** 기본 규칙을 이겼지만,
여기서는 **애드센스 필수 준수 규칙이 지침보다 우선**합니다.
"세 줄로 짧게 써줘" 같은 지침이 규칙을 이겨버리면 이 프로그램의 존재 이유가 사라지기 때문입니다.
말투·분량·구조 외의 요구는 그대로 반영됩니다.

AI 는 지침을 어떻게 반영했는지 `guidelineCheck` 로 스스로 보고하고,
그 내용이 작업표의 **지침 확인** 배지(마우스를 올리면 보입니다)와 진행 로그에 남습니다.

## 참고 예시 글

"이런 식으로 써줘" 하고 보여줄 글을 올리면 AI 가 문체·문단 길이·소제목 방식을 참고합니다.
내용을 베끼지는 않고, 애드센스 규칙과 충돌하면 규칙을 따릅니다.

- `txt` / `md` / `html` / `csv` / `json` 파일을 첨부하거나 직접 붙여넣습니다
- 여러 개 올려두고 체크박스로 켜고 끌 수 있습니다
- 한 개당 최대 20,000자, 전체 합쳐 24,000자까지 프롬프트에 들어갑니다

## 속도와 토큰을 아끼려면

`claude -p` 는 **호출 한 번당** CLI 자체 시스템 프롬프트로만 3만 토큰 넘게 씁니다.
따라서 글자 수보다 **호출 횟수**가 비용을 좌우합니다.

| 설정 | 권장값 | 효과 |
|---|---|---|
| 사용할 AI 모델 | Sonnet 5 | 1,800자 + 표 + 항목별 상세를 한 번에 채우면서 속도도 쓸 만합니다 |
| 자료 조사 | 필요할 때만 켜기 | 검색이 붙으면 호출이 2회로 늘고 글 하나에 3~5분 걸립니다 |
| 검색 횟수 상한 | 4~5 | 더 올려도 출처가 크게 늘지 않고 시간만 늡니다 |
| 보정 재요청 횟수 | 1 | 0으로 두면 호출이 줄지만 미준수 글이 그대로 올라갑니다 |
| 최소 분량 | 1,800 | 더 올리면 출력 토큰과 시간이 함께 늡니다 |
| 주제의 항목 수 | 12 이하 | 13개부터는 표를 나눠 받느라 호출이 늘어납니다 |
| 참고 예시 | 필요할 때만 켜기 | 예시는 호출마다 프롬프트에 실려 갑니다 |

Haiku 4.5 는 가장 빠르지만 1,800자 이상 + 표 + 항목별 상세를 한 번에 채우기엔 약해서
보정 호출이 늘어나는 경우가 많습니다.

## 실행이 자꾸 실패할 때

먼저 **설정 → [선택한 모델로 연결 테스트]** 와 **1번 칸 → [연결 확인]** 을 눌러보세요.
주제를 100개 돌리기 전에 두 가지 연결이 모두 살아 있는지 한 번에 확인할 수 있습니다.

| 증상 | 원인과 해결 |
|---|---|
| `인증에 실패했습니다 (401)` | 사용자 이름이나 응용 프로그램 비밀번호가 틀렸습니다. 새로 발급해 보세요. 일부 호스팅은 `Authorization` 헤더를 지우므로, 그 경우 `.htaccess` 에 `SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1` 을 추가해야 합니다 |
| `권한이 없습니다 (403)` | 그 계정에 글쓰기 권한이 없습니다. 기여자 이상 권한이 필요합니다 |
| `REST API 경로를 찾지 못했습니다 (404)` | 주소가 틀렸거나 REST API 를 막는 플러그인(보안 플러그인이 흔합니다)이 있습니다 |
| `JSON 이 아닌 응답을 보냈습니다` | 보안 플러그인·캐시·방화벽이 요청을 가로챘습니다. 응답 앞부분이 오류 메시지에 함께 나옵니다 |
| 응용 프로그램 비밀번호 칸이 안 보임 | 사이트가 http 이거나 플러그인이 기능을 껐습니다 |
| `모델을 쓸 수 없는 플랜일 수 있습니다` | 구독 플랜에서 그 모델을 못 씁니다. Sonnet 5 나 기본값으로 바꾸세요 |
| `사용량 한도에 걸린 것 같습니다` | 구독 사용량을 다 썼습니다. 자동으로 일시정지되니 잠시 뒤 [이어서 실행]을 누르세요 |
| `claude CLI 를 찾을 수 없습니다` | `npm install -g @anthropic-ai/claude-code` 후 `claude` 로 한 번 로그인하세요 |
| 실행이 중간에 멈춤 | 기본값은 **멈추지 않고 끝까지** 갑니다. 멈췄다면 설정의 "연속 실패 시 멈춤" 이 0이 아니거나, 사용량 한도에 걸려 일시정지된 것입니다 |
| `AI가 이 주제를 거절했습니다` | 그 주제로는 사실이 아닌 내용을 지어내야 해서 모델이 거절한 경우입니다. **건너뜀**으로 표시하고 다음 주제로 넘어갑니다. 주제를 "확인된 위험 신호" 처럼 단정적인 말 대신 "일반적으로 거론되는 특징" 으로 바꾸면 써집니다 |
| `3000번 포트는 이미 다른 프로그램이 쓰고 있습니다` | 경고일 뿐입니다. 3001, 3002... 로 알아서 옮겨 엽니다. 창에 찍힌 주소로 접속하세요 |
| `PORT=3001 : 용어가 인식되지 않습니다` | PowerShell 에는 그 문법이 없습니다. `$env:PORT=3001` 을 먼저 치고 그다음 줄에 `npm start` 를 치세요 |
| `Cannot find package 'express'` | `npm install` 을 아직 안 하셨습니다. 받아온 것은 소스뿐이고 부품은 따로 받아야 합니다 |
| 준수 검사를 계속 통과 못 함 | 최소 분량을 낮추거나 모델을 Opus 5 로 올려보세요. 어느 항목에서 걸리는지는 준수 배지에 마우스를 올리면 보입니다 |
| `웹 검색이 실제로 실행되지 않았습니다` | 검색을 0회 돌리고 답만 온 경우입니다. 4번 칸의 **[웹 검색이 실제로 되는지 시험]** 을 눌러보고, `claude` CLI 를 최신 버전으로 올린 뒤 구독 플랜에서 웹 검색을 쓸 수 있는지 확인하세요. 그 상태로 나온 글은 검색 결과가 아니니 내용을 꼭 대조하세요 |
| 글 하나에 너무 오래 걸림 | 자료 조사가 켜져 있으면 글 하나에 3~5분이 정상입니다. 급하면 4번 칸에서 검색 횟수를 줄이거나 조사를 끄세요 |
| 순위표가 100행까지 안 채워짐 | 로그에 "더 채워지지 않아 남은 시도를 건너뜁니다" 가 뜨면 그 주제에 항목이 실제로 그만큼 없는 경우입니다. 목표 개수를 낮추거나 주제를 넓히세요 |
| 이미지 생성이 `404` | 자동 모드면 알아서 다음 모델로 넘어갑니다. 모델을 직접 적어 두셨다면 그 칸을 비워 자동으로 돌리세요 |
| `쓸 수 있는 이미지 생성 모델이 하나도 없습니다` | 그 키로는 이미지 생성이 안 되는 경우입니다. aistudio.google.com 에서 키를 다시 발급해 보세요 |
| 썸네일 한글이 깨짐 | 싼 모델이 한글을 못 그리는 경우입니다. 로그에 몇 번째 시도에서 걸렸는지 남습니다. 계속 그러면 설정에서 **배경만 그리기**로 바꾸세요 (한글이 절대 안 깨집니다) |
| 출처 목록에 엉뚱한 블로그가 섞임 | 공식 출처를 우선하라고 지시하지만 완벽하지 않습니다. `research.json` 을 열어 확인하고, 발행 전에 목록에서 빼세요 |
| 썸네일만 안 들어감 | 미디어 업로드가 막힌 경우입니다. 글은 그대로 저장됩니다. 호스팅의 업로드 용량 제한을 확인해 보세요 |
| 크로미움 설치 실패 | 회사 네트워크에서 자주 막힙니다. 이미 설치된 크롬 경로를 `run.chromiumPath` 나 `CHROMIUM_PATH` 로 지정하세요 |

오류 원문은 `data/logs/claude-fail-*.log` 에, 서버 로그는 `data/logs/server-*.log` 에 남습니다.

## 안전장치

- **발행하지 않습니다.** `createDraft()` 는 `status` 가 `draft` 가 아니면 요청 자체를 거부합니다.
  블로거판에서 [저장]과 [게시] 버튼을 구분하던 장치와 같은 역할입니다.
- **비밀번호를 밖으로 내보내지 않습니다.** `data/settings.json`(권한 600)에만 저장되고,
  대시보드로 내려보내는 설정에서는 값을 빼고 "채워짐" 여부만 보냅니다.
  화면의 마스킹 표시(`●●●●`)를 그대로 저장해도 진짜 값을 덮어쓰지 않습니다.
- **본문에 태그를 주입할 수 없습니다.** AI 응답은 전부 이스케이프하고 `<b>` 강조만 되살립니다.
- **연속 실패 시 멈춥니다.** 같은 이유로 3건이 연속 실패하면 남은 주제를 태우지 않고 중단합니다.

## 알아두실 점

- 발행이 아니라 **임시저장**만 합니다. 글의 사실관계와 최종 품질은 사람이 확인하고 발행하세요.
- 애드센스 승인은 글 품질만으로 결정되지 않습니다. 사이트 연령, 필수 페이지(개인정보처리방침,
  문의), 글 개수, 방문자 유입 등도 함께 봅니다. 이 프로그램은 그중 **글 품질 부분**을 돕습니다.
- 짧은 시간에 많은 글을 자동으로 올리면 호스팅의 요청 제한에 걸릴 수 있습니다.
  기본 대기 시간(20~60초)을 너무 줄이지 말고, 한 번에 처리하는 양도 나눠서 돌리시길 권합니다.
- 응용 프로그램 비밀번호는 워드프레스 관리자에서 언제든 따로 폐기할 수 있습니다.
  로그인 비밀번호를 바꿀 필요가 없습니다.
