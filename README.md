# 워프러시 (wprush)

엑셀에서 복사한 주제 목록을 붙여넣으면, AI가 주제마다 **구글 애드센스 승인 기준을 지킨 정보성 글**과
썸네일을 만들어 **워드프레스에 임시저장**해 주는 로컬 대시보드입니다.

네이버 블로그용 [파이어러시](https://github.com/jettyy/firerush),
구글 블로거용 [블로거러시](https://github.com/jettyy/blogger)와 같은 방식이고,
글을 올리는 방법과 글이 지켜야 할 규칙을 워드프레스·애드센스에 맞춰 바꿨습니다.

- 글 생성: `claude -p` (Claude Code CLI 헤드리스 모드) → **구독 요금제 그대로 사용**, 토큰 종량 과금 없음
- 애드센스 준수: 분량·문체·표·구조를 **프로그램이 직접 검사**하고, 어긋나면 그 항목만 짚어 다시 쓰게 함
- 워드프레스 접속: **공식 REST API + 응용 프로그램 비밀번호**. 브라우저 로그인도, 화면 자동화도 없음
- 본문 형식: **구텐베르크 블록 마크업**. 문단·소제목·목록·표가 블록 에디터에서 그대로 편집됨
- 함께 지정: 대표 이미지, 카테고리, 태그, 영문 슬러그, 요약(발췌문)
- 썸네일: AI가 문구·색상을 설계 → HTML 템플릿 렌더링 → Playwright 스크린샷 (추가 비용 0원)
- 결과물: 워드프레스 초안 + `post.md`(구텐베르크에 붙여넣을 마크다운) + `preview.html`
- 발행은 하지 않습니다. **임시저장까지만** 하고, 사실 확인과 발행은 사람이 합니다.

## 블로거 버전과 달라진 점

| | 블로거러시 (블로거) | 워프러시 (워드프레스) |
|---|---|---|
| 접속 | Playwright 로 구글 로그인 창 | **REST API + 응용 프로그램 비밀번호** |
| 브라우저 | 로그인용 + 썸네일용 2개 | 썸네일 렌더링용 1개뿐 |
| 본문 넣는 법 | 에디터의 [HTML 보기]에 입력 | **API 로 한 번에 전송** (선택자 깨질 일 없음) |
| 본문 형식 | 인라인 style 을 박은 HTML | **구텐베르크 블록 마크업** (색·여백은 테마에 맡김) |
| 소제목 | `<h3>` | `<h2>` + `<h3>` (글 제목이 이미 H1) |
| 이미지 | 에디터에 업로드 후 HTML 떼어내기 | 미디어 API 업로드 → **대표 이미지**로도 지정 |
| 분류 | 라벨 | 카테고리 1개 + 태그 여러 개 (ID 로 정확히 지정) |
| 주소 | 자동 | AI가 만든 **영문 슬러그** |
| 더보기 | `<!--more-->` | `<!-- wp:more -->` 블록 |
| 글 규칙 | 일반 블로그 글 | **애드센스 승인 기준 자동 검사** |

## 애드센스 승인 규칙을 어떻게 지키는가

이 프로그램의 핵심입니다. 규칙을 프롬프트에 적어 넣는 것만으로는 부족합니다.
모델이 안 지킨 채로 나와도 그대로 저장되기 때문입니다.

그래서 `src/content/adsense.js` 한 곳에 규칙을 정의하고, **같은 정의에서 두 가지를 만들어 냅니다.**

1. 글을 쓰기 전 프롬프트에 들어갈 **지시문**
2. 나온 글을 실제로 검사하는 **검사기**

검사에 걸리면 걸린 항목만 짚어 다시 쓰게 하고(기본 1회), 통과할 때까지 확인합니다.
지시와 검사가 한 파일에 묶여 있어서 따로 놀 수가 없습니다.

| 규칙 | 검사 내용 |
|---|---|
| 분량 | 공백 제외 1,800자 이상 (설정에서 조정) |
| 종결어미 | `~습니다`, `~입니다` 형태가 85% 이상. `~함`, `~임` 개조식은 발견 즉시 실패 |
| 소제목 구조 | H2 3개 이상 + H3 1개 이상. 본문에 H1 금지 |
| 선정 기준 | 서두에 "무엇을 기준으로 골랐는지" 단락이 있는지 |
| 비교 표 | 2행 2열 이상의 표가 최소 1개 |
| 불렛 포인트 | 목록이 최소 1개 |
| 항목별 상세 | 항목형 글에서 각 항목마다 세부 소제목 3개 이상 (상세 설명 / 자격 요건 / 활용 분야 / 장단점 / 준비 팁) |
| 서두 인사말 금지 | "안녕하세요", "이번 포스팅에서는", "알아보겠습니다" 로 시작하지 않는지 |
| 기호·이모지 | 별표, 화살표, 이모지 등 장식 기호가 본문에 있는지 |
| 마무리 | 요약과 독려가 담긴 마무리 단락이 충분한지 |

결과는 작업표의 **준수** 열에 `10/10` 처럼 표시되고, 마우스를 올리면 항목별 판정이 보입니다.
`설정 > 끝내 못 고치면 저장하지 않기` 를 켜면 규칙을 못 지킨 글은 아예 올리지 않습니다.

> 검사기는 형식을 봅니다. **사실관계는 사람이 확인해야 합니다.**
> AI 는 실시간 검색을 하지 않으므로, 발행 전에 수치와 제도 내용을 직접 확인하세요.

## 주제에 따라 글 모양이 달라집니다

애드센스 규칙은 "각 항목마다 상세 설명, 자격 요건, 활용 분야, 장단점, 팁을 넣을 것" 을 요구합니다.
그래서 항목이 몇 개냐에 따라 구조를 바꿉니다.

| 주제 예시 | 모양 | 어떻게 쓰는가 | 호출 횟수 |
|---|---|---|---|
| `국가기술자격증 TOP 5` | 항목별 상세형 | 항목마다 H2 섹션 1개 + H3 세부 소제목 5개 | 1회 |
| `자격증 7가지 추천` | 항목별 상세형 | 위와 같음 | 1회 |
| `유튜브 구독자 TOP100` | 대형 비교표형 | 표를 50행씩 나눠 받고, 대표 항목만 상세하게 | 3회 |
| `전세 계약 전 확인할 서류` | 정보 정리형 | H2 소제목 중심 + H3 세부 소제목 | 1회 |

13개 이상이면 항목마다 다섯 항목씩 쓰는 것이 현실적으로 불가능해서 표 중심으로 넘어갑니다.
표는 한 번에 받으면 모델이 "이하 생략" 하거나 잘리므로 구간을 나눠 받고,
빠진 번호가 있으면 그 구간만 다시 요청합니다.

## 준비물

| 항목 | 확인 |
|---|---|
| Node.js 20 이상 | `node -v` |
| Claude Code CLI | `claude --version` — 없으면 `npm install -g @anthropic-ai/claude-code` 후 `claude` 를 한 번 실행해 구독 계정으로 로그인 |
| 워드프레스 5.6 이상 | 응용 프로그램 비밀번호가 이 버전부터 기본 기능입니다 |
| https 사이트 | 워드프레스는 기본적으로 https 에서만 응용 프로그램 비밀번호를 허용합니다 (localhost 예외) |

## 설치와 실행

```bash
npm install
npm run setup      # claude CLI · 썸네일 렌더러 · 워드프레스 연결 확인 (선택)
npm start          # → http://localhost:3000
```

포트를 바꾸려면 `PORT=4000 npm start`.
코드를 고쳤다면 `npm run check` 로 자체 점검을 먼저 돌려보세요.

## 응용 프로그램 비밀번호 발급

로그인 비밀번호가 **아닙니다.** 이 프로그램만 쓸 수 있는 별도의 열쇠이고, 언제든 따로 폐기할 수 있습니다.

1. 워드프레스 관리자 → **사용자 → 프로필**
2. 아래로 내려 **응용 프로그램 비밀번호** 칸
3. 이름을 아무거나 적고 (예: `wprush`) **[새 응용 프로그램 비밀번호 추가]**
4. `xxxx xxxx xxxx xxxx xxxx xxxx` 형태의 비밀번호가 **한 번만** 표시됩니다. 그대로 복사
5. 대시보드 1번 칸에 사이트 주소 · 사용자 이름과 함께 넣고 **[연결 확인]**

칸이 보이지 않는다면 사이트가 http 이거나, 보안 플러그인이 기능을 꺼둔 경우입니다.

## 사용 흐름

1. **워드프레스 연결** — 사이트 주소, 사용자 이름, 응용 프로그램 비밀번호를 넣고 [연결 확인].
   성공하면 계정 권한과 카테고리 목록을 자동으로 읽어 옵니다.
2. **주제 붙여넣기** — 엑셀에서 주제 열을 복사해 그대로 붙여넣습니다.
   한 줄에 주제 하나로 인식하고, 탭으로 나뉜 경우 첫 열만 씁니다.
   머리글(`주제`, `제목` 등)과 중복은 자동으로 걸러냅니다.
3. **지침 & 예시** — AI에게 꼭 지키게 할 내용을 적고, 참고할 예시 글을 올립니다.
4. **준수 규칙 확인** — 최소 분량, 소제목 개수, 보정 횟수를 조정합니다.
5. **설정** — 모델, 독자, 썸네일, 대기 시간 등을 조정합니다.
6. **실행** — 주제를 하나씩 순서대로 처리합니다.
   진행 상황·준수 점검 결과·썸네일이 표에 실시간으로 표시되고,
   저장이 끝나면 **[초안 열기]** 링크가 생깁니다.
7. **확인** — 워드프레스 글 목록의 **임시글**에서 내용과 사실관계를 확인하고 발행하세요.

## 결과물이 남는 곳

```
data/
├── settings.json          설정 (응용 프로그램 비밀번호 포함, 권한 600)
├── jobs.json              작업 목록 (껐다 켜도 유지)
├── wp-site.json           연결 상태 요약
├── examples/              올려둔 참고 예시 글
├── thumbnails/            생성된 썸네일 PNG
├── logs/                  서버 로그 · AI 실패 원문
└── posts/<주제-id>/
    ├── post.json          글 데이터 (준수 점검 결과 포함)
    ├── post.md            구텐베르크에 그대로 붙여넣을 마크다운
    ├── content.html       실제로 전송한 블록 마크업
    └── preview.html       브라우저로 열어 보는 미리보기
```

`data/` 는 git 에 올라가지 않습니다. 워드프레스 저장이 실패해도 글 자체는 여기 남으니
`post.md` 를 열어 블록 에디터에 통째로 붙여넣으면 표와 소제목이 그대로 들어갑니다.

## 설정 항목

| 항목 | 설명 |
|---|---|
| 사이트 주소 / 사용자 이름 / 응용 프로그램 비밀번호 | 워드프레스 연결 정보 |
| 글을 넣을 카테고리 | 계정이 읽어온 카테고리 중에서 고릅니다 |
| 최소 분량 (공백 제외) | 애드센스 권장값 1,800자 |
| H2 소제목 개수 | 규칙상 3~4개 |
| 보정 재요청 횟수 | 검사에 걸렸을 때 다시 쓰게 할 횟수. 호출이 늘어나므로 1회 권장 |
| 끝내 못 고치면 저장하지 않기 | 켜면 규칙 미준수 글을 아예 올리지 않습니다 |
| 서두에 선정 기준 밝히기 / 자주 묻는 질문 넣기 | 승인 심사에서 정보성을 높이는 부분입니다 |
| 사용할 AI 모델 | 드롭다운에서 고릅니다. 목록에 없는 모델은 "직접 입력…"으로 |
| 말투 / 독자 | 프롬프트에 그대로 반영됩니다 (말투는 규칙을 벗어나면 검사에서 걸립니다) |
| "더 읽기" 넣기 | 도입부 뒤에 `<!-- wp:more -->`. 목록 화면에 도입부까지만 보입니다 |
| 태그를 워드프레스 태그로 등록 | AI가 뽑은 태그 3~6개를 찾거나 새로 만들어 붙입니다 |
| AI가 만든 영문 슬러그 사용 | 한글 주소보다 검색에 유리합니다 |
| 썸네일 스타일 / 크기 | `auto`(AI 선택) · `minimal`(권장) · `bold` · `gradient` · `editorial` |
| 썸네일을 본문에 넣기 / 대표 이미지로 지정 | 따로 켜고 끌 수 있습니다 |
| 썸네일에 이모지 허용 | 승인 심사에서는 꺼두는 편이 안전합니다 |
| 글 사이 대기 | 기본 20~60초 무작위. 호스팅의 요청 제한을 피합니다 |
| 재시도 횟수 | 실패한 주제를 자동으로 다시 시도하는 횟수 |

설정 파일에서만 조정 가능한 항목:

- `claude.command` — `claude` 실행 파일 경로 (PATH에 없을 때)
- `claude.timeoutMs` — AI 응답 대기 시간 (기본 420초. 승인글은 길어서 넉넉히 잡았습니다)
- `run.chromiumPath` — 썸네일 렌더링에 쓸 크롬/크로미움 경로 (환경변수 `CHROMIUM_PATH` 도 가능)

## 추가 지침

대시보드 **3번 칸**에 쓰는 내용입니다. 입력하면 자동으로 저장됩니다.
프롬프트의 **맨 앞**과 **맨 끝**에 두 번 들어갑니다.

한 줄에 하나씩 쓰면 더 잘 지킵니다.

```
수도권 기준으로 설명할 것
비용은 대략적인 범위로만 언급할 것
마지막에 준비 체크리스트를 넣을 것
```

블로거판과 한 가지 다릅니다. 거기서는 지침이 **모든** 기본 규칙을 이겼지만,
여기서는 **애드센스 필수 준수 규칙이 지침보다 우선**합니다.
"세 줄로 짧게 써줘" 같은 지침이 규칙을 이겨버리면 이 프로그램의 존재 이유가 사라지기 때문입니다.
말투·분량·구조 외의 요구는 그대로 반영됩니다.

AI 는 지침을 어떻게 반영했는지 `guidelineCheck` 로 스스로 보고하고,
그 내용이 작업표의 **지침 확인** 배지(마우스를 올리면 보입니다)와 진행 로그에 남습니다.

## 참고 예시 글

"이런 식으로 써줘" 하고 보여줄 글을 올리면 AI 가 문체·문단 길이·소제목 방식을 참고합니다.
내용을 베끼지는 않고, 애드센스 규칙과 충돌하면 규칙을 따릅니다.

- `txt` / `md` / `html` / `csv` / `json` 파일을 첨부하거나 직접 붙여넣습니다
- 여러 개 올려두고 체크박스로 켜고 끌 수 있습니다
- 한 개당 최대 20,000자, 전체 합쳐 24,000자까지 프롬프트에 들어갑니다

## 속도와 토큰을 아끼려면

`claude -p` 는 **호출 한 번당** CLI 자체 시스템 프롬프트로만 3만 토큰 넘게 씁니다.
따라서 글자 수보다 **호출 횟수**가 비용을 좌우합니다.

| 설정 | 권장값 | 효과 |
|---|---|---|
| 사용할 AI 모델 | Sonnet 5 | 1,800자 + 표 + 항목별 상세를 한 번에 채우면서 속도도 쓸 만합니다 |
| 보정 재요청 횟수 | 1 | 0으로 두면 호출이 줄지만 미준수 글이 그대로 올라갑니다 |
| 최소 분량 | 1,800 | 더 올리면 출력 토큰과 시간이 함께 늡니다 |
| 주제의 항목 수 | 12 이하 | 13개부터는 표를 나눠 받느라 호출이 늘어납니다 |
| 참고 예시 | 필요할 때만 켜기 | 예시는 호출마다 프롬프트에 실려 갑니다 |

Haiku 4.5 는 가장 빠르지만 1,800자 이상 + 표 + 항목별 상세를 한 번에 채우기엔 약해서
보정 호출이 늘어나는 경우가 많습니다.

## 실행이 자꾸 실패할 때

먼저 **설정 → [선택한 모델로 연결 테스트]** 와 **1번 칸 → [연결 확인]** 을 눌러보세요.
주제를 100개 돌리기 전에 두 가지 연결이 모두 살아 있는지 한 번에 확인할 수 있습니다.

| 증상 | 원인과 해결 |
|---|---|
| `인증에 실패했습니다 (401)` | 사용자 이름이나 응용 프로그램 비밀번호가 틀렸습니다. 새로 발급해 보세요. 일부 호스팅은 `Authorization` 헤더를 지우므로, 그 경우 `.htaccess` 에 `SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1` 을 추가해야 합니다 |
| `권한이 없습니다 (403)` | 그 계정에 글쓰기 권한이 없습니다. 기여자 이상 권한이 필요합니다 |
| `REST API 경로를 찾지 못했습니다 (404)` | 주소가 틀렸거나 REST API 를 막는 플러그인(보안 플러그인이 흔합니다)이 있습니다 |
| `JSON 이 아닌 응답을 보냈습니다` | 보안 플러그인·캐시·방화벽이 요청을 가로챘습니다. 응답 앞부분이 오류 메시지에 함께 나옵니다 |
| 응용 프로그램 비밀번호 칸이 안 보임 | 사이트가 http 이거나 플러그인이 기능을 껐습니다 |
| `모델을 쓸 수 없는 플랜일 수 있습니다` | 구독 플랜에서 그 모델을 못 씁니다. Sonnet 5 나 기본값으로 바꾸세요 |
| `사용량 한도에 걸린 것 같습니다` | 구독 사용량을 다 썼습니다. 자동으로 일시정지되니 잠시 뒤 [이어서 실행]을 누르세요 |
| `claude CLI 를 찾을 수 없습니다` | `npm install -g @anthropic-ai/claude-code` 후 `claude` 로 한 번 로그인하세요 |
| `연속 3건이 같은 이유로 실패해 실행을 멈춥니다` | 설정이 잘못됐다는 뜻입니다. 남은 주제를 태우지 않으려고 멈춘 것이니 오류 내용을 먼저 보세요 |
| 준수 검사를 계속 통과 못 함 | 최소 분량을 낮추거나 모델을 Opus 5 로 올려보세요. 어느 항목에서 걸리는지는 준수 배지에 마우스를 올리면 보입니다 |
| 썸네일만 안 들어감 | 미디어 업로드가 막힌 경우입니다. 글은 그대로 저장됩니다. 호스팅의 업로드 용량 제한을 확인해 보세요 |
| 크로미움 설치 실패 | 회사 네트워크에서 자주 막힙니다. 이미 설치된 크롬 경로를 `run.chromiumPath` 나 `CHROMIUM_PATH` 로 지정하세요 |

오류 원문은 `data/logs/claude-fail-*.log` 에, 서버 로그는 `data/logs/server-*.log` 에 남습니다.

## 안전장치

- **발행하지 않습니다.** `createDraft()` 는 `status` 가 `draft` 가 아니면 요청 자체를 거부합니다.
  블로거판에서 [저장]과 [게시] 버튼을 구분하던 장치와 같은 역할입니다.
- **비밀번호를 밖으로 내보내지 않습니다.** `data/settings.json`(권한 600)에만 저장되고,
  대시보드로 내려보내는 설정에서는 값을 빼고 "채워짐" 여부만 보냅니다.
  화면의 마스킹 표시(`●●●●`)를 그대로 저장해도 진짜 값을 덮어쓰지 않습니다.
- **본문에 태그를 주입할 수 없습니다.** AI 응답은 전부 이스케이프하고 `<b>` 강조만 되살립니다.
- **연속 실패 시 멈춥니다.** 같은 이유로 3건이 연속 실패하면 남은 주제를 태우지 않고 중단합니다.

## 알아두실 점

- 발행이 아니라 **임시저장**만 합니다. 글의 사실관계와 최종 품질은 사람이 확인하고 발행하세요.
- 애드센스 승인은 글 품질만으로 결정되지 않습니다. 사이트 연령, 필수 페이지(개인정보처리방침,
  문의), 글 개수, 방문자 유입 등도 함께 봅니다. 이 프로그램은 그중 **글 품질 부분**을 돕습니다.
- 짧은 시간에 많은 글을 자동으로 올리면 호스팅의 요청 제한에 걸릴 수 있습니다.
  기본 대기 시간(20~60초)을 너무 줄이지 말고, 한 번에 처리하는 양도 나눠서 돌리시길 권합니다.
- 응용 프로그램 비밀번호는 워드프레스 관리자에서 언제든 따로 폐기할 수 있습니다.
  로그인 비밀번호를 바꿀 필요가 없습니다.
